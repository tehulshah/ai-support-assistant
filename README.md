# AI Customer Support Assistant

An interactive Streamlit application that uses machine learning to classify customer support messages, estimate their priority, and generate a suggested response for a support agent.

## Features

- **Ticket categorization:** Predicts a support category from the message text, including Billing, Technical, Account, General Inquiry, and Fraud.
- **Priority prediction:** Classifies incoming messages as High, Medium, or Low priority.
- **Suggested replies:** Builds a reply using the message, predicted category, priority, and reusable response wording.
- **Text preprocessing and model training:** Includes a notebook documenting the data preparation and model-training workflow.
- **Simple interface:** Enter a customer message and select **Generate Response** to see a suggested reply.

> This is a project/demo assistant. Predictions and generated replies should be reviewed by a human before being sent to a customer. Model quality depends on the training data and has not been independently validated for production use.

## Tech Stack

- Python
- Streamlit
- pandas and NumPy
- scikit-learn
- TF-IDF text features
- Logistic Regression classifiers

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tehulshah/ai-support-assistant.git
cd ai-support-assistant
```

### 2. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the application

From the repository root, run:

```bash
streamlit run app/app.py
```

Streamlit will print a local URL (usually `http://localhost:8501`) to open in your browser.

## How It Works

1. A user enters a customer support message in the Streamlit interface.
2. The fitted TF-IDF vectorizer converts the text into numeric features.
3. The category classifier predicts the message's support category.
4. The priority classifier estimates its urgency.
5. The application combines the original message, predicted category, priority, and response wording to produce a suggested reply.

The saved model and vectorizer files are loaded from the `app/` directory when the application starts.

## Model Development

The notebook in `notebooks/data_preprocessing.ipynb` covers data preparation and the text-classification workflow. The current dependency list is in `requirements.txt`.

To retrain or modify the models, review the notebook and ensure the exported model files remain compatible with the application. Pickle files should only be loaded from sources you trust.

## Limitations

- Predictions are based on patterns learned from the available dataset and may be incorrect for unfamiliar or ambiguous messages.
- Priority prediction is an estimate, not a guarantee of actual business urgency.
- Generated replies are template-based suggestions rather than responses generated by a large language model.
- Review predictions and replies before using them in a real customer-support workflow.
